# 教师工作台 v1.0820

本地运行的班主任/教师工作台，一站式管理学生、成绩、考勤、通知、作业台账。纯本地、零云端，数据完全在您掌控。

## 特性

- ✅ **零依赖**：无需安装数据库、无需配置服务器
- ✅ **纯本地**：所有数据存储在本地文件系统，断网也能用
- ✅ **自动备份**：导入数据前自动快照，操作失误随时恢复
- ✅ **双目录隔离**：代码(`app/`)与数据(`data/`)完全分离，热更新不丢失数据
- ✅ **原子写入**：停电/崩溃不会损坏数据
- ✅ **一键启动**：双击 `打开教师工作台.vbs` 即可运行

## 快速开始

### 1. 启动

双击 **打开教师工作台.vbs**（或桌面快捷方式），浏览器自动打开 `http://127.0.0.1:8731/`

### 2. 导入数据

首次使用需要导入 Excel 模板（22 张表）：

1. 点击「数据管理」→「导入数据」
2. 上传 Excel（或从 `templates/` 文件夹准备好的模板）
3. 系统自动生成备份，确认后生效

### 3. 迁移到其他电脑

直接复制整个「教师工作台」文件夹即可（数据自动跟随）。

## 目录结构

```
教师工作台/          ← 父文件夹（整拷贝即迁移）
├── app/              ← 应用代码（热更新只动这里）
```

## 数据保护

1. **应用/数据隔离**：`app/` 和 `data/` 是两个独立子文件夹。热更新替换 `app/` 即可，`data/` 完全不受影响。
2. **导入自动快照**：每次「导入数据」（合并或替换）前，系统自动在 `data/backup/` 生成 `pre-import-时间戳.json` 快照 — 导入不满意随时恢复。
3. **清空自动快照**：清空本机数据前同样自动生成 `pre-clear-时间戳.json`。
4. **原子写入**：所有台账保存都是「先写临时文件再原子替换」，异常中断不会损坏数据。
5. **导入失败自动回滚**：导入内容损坏时自动恢复原数据。

## 备份与恢复

- **手动备份**：命令行执行 `app\wb.js backup` → 生成到 `data/backup/`
- **完整备份**：直接复制整个 `data/` 文件夹即可（包括所有台账与附件）
- **恢复**：
  - 从自动快照恢复：把 `data/backup/pre-import-xxx.json` 用 `app\wb.js import <文件> --replace` 导入
  - 或直接用备份文件替换 `data/records/` 下对应内容（需先停止服务）

## 命令行工具（可选）

```bash
node app/wb.js status          查看状态
node app/wb.js backup          生成备份
node app/wb.js export <file>   导出完整备份
node app/wb.js import <file>   导入备份（默认合并，--replace 覆盖）
node app/wb.js start / stop    启停服务
```
